# iSee

윈도우·맥용 초고속 이미지 뷰어 & 사진 정리기. 계획은 [docs/PLAN.md](docs/PLAN.md), 속도 측정 결과는 [docs/BENCH.md](docs/BENCH.md).

## 설치

최신 설치 파일: **https://github.com/janghwansangai/isee-releases/releases/latest**

- **맥** (애플 실리콘·인텔 모두): `iSee_…_universal.dmg`를 열고 iSee를 응용 프로그램 폴더로 끌어 놓습니다. 서명하지 않은 앱이라 처음 한 번은 Finder에서 iSee를 **우클릭 › 열기**로 엽니다.
- **윈도우** 10·11: `iSee_…_x64-setup.exe`를 실행합니다 (관리자 권한 필요 없음). SmartScreen 경고가 뜨면 **추가 정보 › 실행**을 누릅니다.
- 새 버전이 나오면 앱이 실행 15초 뒤(하루 한 번) 알려 주고, 누르면 받아서 다시 시작합니다. 메뉴 iSee(윈도우는 파일) › **업데이트 확인…**으로 직접 확인할 수도 있습니다. 업데이트 파일은 서명을 확인한 뒤에만 설치합니다.

## 새 버전 내보내기 (개발자용)

1. `app/src-tauri/tauri.conf.json`과 맨 위 `Cargo.toml`(workspace.package)의 `version`을 올리고 커밋합니다.
2. 태그를 올립니다: `git tag v0.1.1 && git push origin main v0.1.1` → GitHub Actions가 맥·윈도우 설치 파일과 업데이트 파일을 만들어 비공개 저장소의 릴리스 초안에 올립니다.
3. 맥에서 `scripts/publish.sh v0.1.1` → 공개 배포 저장소(isee-releases)에 올라가고, 사용자 앱이 업데이트를 받습니다.

업데이트 서명 키는 이 맥의 `~/.tauri/isee-updater.key`(비밀번호는 같은 폴더)에만 있고, 저장소에는 GitHub Secrets로만 들어 있습니다. **키를 잃어버리면 기존 사용자에게 업데이트를 보낼 수 없으니** 따로 안전하게 보관하세요.

## 구조

```
crates/isee-core/   Rust 엔진: 폴더 목록, 디코딩(ImageIO·zune-jpeg), 썸네일 캐시(SQLite), 우선순위 작업 큐, 파일 작업
crates/isee-bench/  속도 측정 도구
app/src-tauri/      Tauri 앱 (엔진 ↔ 화면 연결, isee:// 이미지 전달, 메뉴바)
app/src/            Svelte 화면 (탐색기, 썸네일 그리드, 뷰어)
```

## 실행

```bash
cd app && npm install && npm run tauri dev
```

배포용 빌드 (맥 .app):

```bash
cd app && npm run tauri build -- --bundles app
```

## 속도 측정

```bash
cargo build --release -p isee-bench
./target/release/isee-bench gen /tmp/isee-testset
./target/release/isee-bench run /tmp/isee-testset docs/BENCH.md
# 비슷한 사진 정답 세트와 정확도·속도
./target/release/isee-bench gen-similar /tmp/isee-similar
./target/release/isee-bench similar /tmp/isee-similar
# 날짜·장소 정리 세트와 속도 (좌표 확인: isee-bench place 37.56,126.97)
./target/release/isee-bench gen-organize /tmp/isee-organize
./target/release/isee-bench organize /tmp/isee-organize /tmp/isee-testset/folder
```

## 우클릭 빠른 변환 (2단계)

사진을 우클릭하면 회전, 크기, 형식, 용량, 화질, 공유용 저장, 워터마크, 이름 일괄 변경, 저장 방식을 바로 고를 수 있습니다. 여러 장을 고르면 한 번에 처리하고, 모든 작업은 ⌘Z로 되돌릴 수 있습니다.
JPEG·HEIC 회전은 회전 값만 바꾸므로 화질이 그대로입니다.

Finder·탐색기 우클릭에서도 쓰려면: 메뉴 **정리 › Finder 우클릭(빠른 동작)에 iSee 변환 넣기**.
명령줄로도 쓸 수 있습니다:

```bash
iSee.app/Contents/MacOS/isee-app --convert resize=1920 사진1.jpg 사진2.jpg
```

작업: `rotate=cw|ccw|180`, `resize=1920` 또는 `resize=50%`, `format=jpeg|png|webp|heic|avif|tiff|bmp`, `size=1000000`(바이트 이하), `quality=85`, `share`

## 비교와 빠른 고르기 (3단계)

- **비교**: 사진을 2~9장 고르고 `C` (또는 툴바 "비교", 우클릭 "비교하기"). 확대·이동은 모든 칸이 함께 움직입니다.
  칸을 클릭하거나 숫자키로 남길 사진을 표시하고 `Delete`를 누르면 나머지가 휴지통으로 갑니다 (⌘Z로 되돌림). 2장이면 겹쳐 보기·깜빡이기(`O`, `Space`)도 됩니다.
- **빠른 고르기 모드** (툴바 "빠른 고르기" 또는 메뉴 정리 › 빠른 고르기 모드): `P` 남김, `X` 버림, `U` 지우기, `0~5` 별점을 매기면 다음 사진으로 넘어갑니다.
  툴바에서 남김만·미정만·버림만 골라 보고, "버린 N장 휴지통"으로 한 번에 정리합니다. 표시는 파일을 건드리지 않고 앱에 저장합니다.

## 비슷한 사진 정리 (4단계)

툴바 **비슷한 사진** (또는 메뉴 정리 › 비슷한 사진 정리…, ⌘⇧S). 지금 폴더의 사진을 분석해 비슷한 것끼리 묶고, 묶음마다 가장 잘 나온 사진에 ★ 추천을 붙입니다.

- **묶는 정도** 슬라이더, **추천 기준**(선명한 것·노출·노이즈·해상도·나중에 찍은 것), **묶음마다 남길 장수**를 바꾸면 즉시 다시 묶습니다 (사진을 다시 읽지 않음).
- 사진을 클릭하면 남김/정리가 바뀌고, **비교**를 누르면 남길 사진이 미리 골라진 비교 화면이 열립니다.
- **나머지 N장 휴지통**(묶음 하나) · **추천 외 N장 휴지통**(전체) · **남김·버림 표시만**(지우지 않고 남김·버림 표시). 모두 ⌘Z로 되돌립니다.
- 탭: **똑같은 파일**(내용이 완전히 같은 사본), **흐림**, **너무 어두움**, **너무 밝음**.
- 분석은 이 화면을 열었을 때만 하고, 한 번 분석한 사진은 저장해 둡니다. 뷰어·비교 화면을 여는 동안에는 멈춥니다.

## 날짜·장소별 정리 (5단계)

메뉴 **정리 › 날짜·장소별 정리…** (⌘⇧D), 또는 사진 우클릭 › **날짜·장소별로 정리…**. 2장 이상 골랐으면 그 사진만, 아니면 지금 폴더 전체(하위 폴더 포함 가능)를 정리합니다.

- **기준**: 날짜 · 장소 · 날짜+장소 · 이벤트(촬영 간격으로 여행·행사를 나눔). 폴더 이름 규칙은 예시를 보고 고르거나 `{년} {월} {일} {장소} {기간}`으로 직접 씁니다 ("/"는 하위 폴더).
- **장소 단위**: 나라 · 시·도 · 시·군·구 · 동네 (예: 대한민국 / 제주 / 제주 서귀포시 / 제주 서귀포시 중문동, 해외는 "일본 오사카"). 지명은 앱에 넣어 둔 데이터로 찾아 위치가 인터넷으로 나가지 않습니다.
- 날짜는 EXIF 촬영 시각 → 동영상 촬영 시각 → 파일 이름 속 날짜 → 파일 수정 시각 순서로 찾습니다. 수정 시각으로 정한 사진과 위치 없는 사진은 미리보기 위쪽에 따로 표시합니다.
- 미리보기에서 폴더 이름을 고치거나 폴더를 뺄 수 있습니다. **이동** 또는 **복사**, 정리할 위치를 고른 뒤 실행하고, 전체를 ⌘Z 한 번으로 되돌립니다.
- RAW+JPEG, 라이브 포토(HEIC+MOV), 보정 정보(.xmp, .aae)는 함께 옮깁니다.

## 편집기 (6단계)

사진을 고르고 `E` (또는 메뉴 정리 › 사진 편집…, ⌘E, 우클릭 › 편집…).

- 도구: 선택·이동(V) · 자르기(C, 자유·원본·1:1·4:3·3:4·16:9·9:16) · 펜(P) · 형광펜(H) · 선·밑줄(L) · 화살표(A) · 사각형(R) · 원(O) · 텍스트(T) · 모자이크(M) · 흐리게(B), 왼쪽·오른쪽 90° 회전, 좌우·상하 반전. 1·2·3으로 굵기·글자 크기.
- Shift: 선은 수평·수직·45°, 도형은 정사각형·정원. 텍스트는 클릭 후 입력하고 Enter, 선택 도구로 옮기고 두 번 클릭해 고칩니다.
- 보정: 밝기·대비·채도 (두 번 클릭하면 원래대로).
- 그린 것은 저장 전까지 개체로 남아 옮기고, 색을 바꾸고, 지울 수 있습니다. ⌘Z / ⇧⌘Z로 한 단계씩 되돌립니다.
- **새 파일로 저장**(⌘S, `이름_편집.jpg`) 또는 **원본에 저장**(원본 보관, ⌘Z로 되돌림). 저장 설정에서 형식(JPG·PNG·WebP·HEIC)·크기·화질을 고릅니다. 촬영 날짜·위치 정보는 그대로 남습니다.

## 동영상·PDF·클라우드 (7단계)

- 메뉴 **보기 › 파일 종류**에서 동영상·PDF를 켜면 썸네일(▶, PDF 표시)이 나옵니다. 동영상을 열면 앱 안에서 재생합니다 (mp4·mov·m4v·webm, Esc로 닫기).
- 구글 드라이브·iCloud·OneDrive·Synology Drive 폴더(왼쪽 "클라우드")에서 아직 내려받지 않은 파일은 ☁ 표시가 붙고, 썸네일은 클라우드 앱이 가진 미리보기를 써서 **원본을 내려받지 않습니다**. 크게 보거나 편집할 때만 내려받습니다.
- 이동·삭제는 동기화 폴더 안의 파일 정보만 바뀌므로 바로 끝나고, 동기화는 각 클라우드 앱이 합니다.

## 인물 (8단계, 선택 모듈)

툴바 **인물** (또는 메뉴 정리 › 인물…, ⌘⇧P). 처음에는 설치 안내가 나오고, **설치**를 누르면 얼굴 인식 모델 2개(37MB)를 OpenCV Zoo에서 내려받습니다. 사진과 얼굴 데이터는 인터넷으로 나가지 않습니다.

- 지금 폴더(하위 폴더 포함 가능)의 얼굴을 찾아 같은 사람끼리 묶습니다. 분석은 백그라운드에서 하고 사진을 보는 동안 멈춥니다.
- 묶음에 이름을 붙이면, 다른 폴더의 새 사진에서도 그 사람을 알아보고 "확인 필요"로 넣습니다 (노란 테두리). 맞으면 **모두 맞음**, 틀리면 골라서 **이 사람 아님**.
- **다른 인물과 합치기**, 같은 이름으로 저장하면 자동으로 합쳐집니다. 얼굴을 두 번 클릭하면 사진을 크게 봅니다.
- **인물별 폴더로 복사** (여러 사람이 나온 사진은 사람 수만큼) 또는 **주인공 기준 이동** (가장 크게 나온 사람, 비슷한 크기로 여럿이면 "단체 사진"). ⌘Z로 되돌립니다.
- **얼굴 데이터 지우기**로 이 컴퓨터의 얼굴 정보와 이름을 모두 지웁니다.
